## 🎯 O que é este Sistema?

É uma **plataforma digital completa** que permite ao **Salão de Beleza Kelson**:

1. **Aceitar agendamentos online** dos clientes (24h por dia)
2. **Gerir pedidos** de forma centralizada
3. **Atribuir entregas** aos barbeiros
4. **Gerar relatórios** de faturação
5. **Ter visibilidade total** do negócio

---

## 🎯 Problema Resolvido

### ❌ ANTES (WhatsApp manual)

- Cliente tinha que mandar mensagem manualmente
- Confusão de horários (2 clientes no mesmo horário)
- Sem histórico organizado
- Sem estatísticas de receita
- Dificuldade em gerir barbeiros
- Dados dispersos

### ✅ DEPOIS (Sistema Digital)

- Cliente agenda online em 1 minuto
- Sistema bloqueia horários automaticamente
- Histórico completo de pedidos
- Estatísticas em tempo real (dia/semana/mês/ano)
- Gestão fácil de funcionários
- Todos os dados centralizados

---

## 🌐 3 Interfaces Integradas

### 1️⃣ Para o Cliente (Landing Page)

**URL:** https://salao-kelson.netlify.app/

**O que vê:**
- Informações do salão
- Serviços com preços
- Galeria de trabalhos
- Localização com mapa
- **Formulário de agendamento**

**O que faz:**
1. Escolhe serviço
2. Escolhe profissional (com foto)
3. Escolhe data e hora
4. Preenche dados
5. Escolhe pagamento
6. Confirma → WhatsApp automático

### 2️⃣ Para o Admin / Dono (Painel Admin)

**URL:** https://salao-kelson.netlify.app/login.html

**Funcionalidades:**
- **Dashboard** com 4 cards:
  - Hoje: X pedidos | Y Kz
  - Semana: X pedidos | Y Kz
  - Mês: X pedidos | Y Kz
  - Ano: X pedidos | Y Kz
- **Gestão de Pedidos:**
  - Ver todos
  - Marcar "Cliente Chegou"
  - Marcar "Não Compareceu"
  - Ver comprovativo Multicai
- **Gestão de Funcionários:**
  - Adicionar novo
  - Editar dados
  - Desativar/Reativar
- **Finanças:** receita total
- **Relatórios PDF:** exportar por período

### 3️⃣ Para os Barbeiros (Painel Barbeiro)

**URL:** https://salao-kelson.netlify.app/login.html

**Funcionalidades:**
- Ver apenas os SEUS pedidos
- Filtros: Pendentes / Hoje / Semana / Todas
- Estatísticas pessoais
- Marcar "Cliente Chegou"
- Contactar cliente por WhatsApp
