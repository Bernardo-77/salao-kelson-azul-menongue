## ✅ Como Concluir um Pedido

**Quando o cliente chega:**

1. Encontra o pedido na lista
2. Clica **"✅ Cliente Chegou — Receber"**
3. Confirma o valor
4. Sistema marca como concluído
5. Adiciona à tua estatística

**Se o cliente estiver mais de 30 min atrasado**, o sistema pergunta:
- Se queres aplicar taxa de 10%
- Podes escolher sim ou não

---

## ⚠️ Como Marcar "Não Compareceu"

**Quando o cliente não aparece:**

1. Encontra o pedido
2. Clica **"❌ Não Compareceu"**
3. Confirma
4. Pedido fica registado mas não conta para receita

**⚠️ Só usa isto depois de esperar pelo menos 30 minutos.**

## 📝 Regras Importantes

### ✅ DEVES:
- Chegar a tempo ao trabalho
- Confirmar cada cliente ao receber
- Contactar cliente se necessário
- Marcar "Não Compareceu" depois de 30 min

### ❌ NÃO DEVES:
- Concluir pedidos sem cliente presente
- Marcar "Não Compareceu" prematuramente
- Partilhar a tua senha com outros
- Deixar sessão aberta em computador partilhado
